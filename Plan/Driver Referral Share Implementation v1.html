แผนเพิ่มทางแชร์โค้ดคนขับ

2026-09-25 · สถานะ: Completed เฉพาะทางเข้าและหน้าแชร์ในแอป · อ้างอิง Referral Wallet Promotion Plan v2

1. ทดสอบก่อนแก้

ยืนยันว่าโปรไฟล์คนขับมีเมนูชวนเพื่อนและเปิดหน้าแชร์ได้ พร้อมทดสอบเงื่อนไขคนขับสองแบบในทั้งสองธีม

2. ต่อทางเข้า

เพิ่มเมนูในโปรไฟล์คนขับไปหน้า ReferralScreen เดิม โดยไม่เปลี่ยน navigation ของผู้ใช้บทบาทอื่น

3. ข้อมูลแคมเปญ

เพิ่มการ์ดคนขับชวนร้านและคนขับชวนคนขับ ใช้ค่าฐาน ตัวคูณ และขั้นต่ำถอนจาก my_referral_summary เท่านั้น

4. ตรวจและส่งมอบ

flutter test, analyze เฉพาะไฟล์, review, ภาพสว่าง/มืด, บันทึก Obsidian; build เฉพาะเมื่อขยับเวอร์ชันก่อน

ผลตรวจ: widget test ใหม่ 5/5 และ test ทั้งโปรเจกต์ 710/710 ผ่าน; web preview light/dark และ Android debug APK build ผ่าน; code review ไม่พบ blocker
ข้อจำกัด: ไม่มี authenticated UAT ของ RPC/การแชร์จริง/ระบบจ่ายรางวัลหรืออุปกรณ์ Android ต่ออยู่ในรอบนี้; analyze ไฟล์ที่เกี่ยวข้องยังมี info เดิม 1 รายการ
