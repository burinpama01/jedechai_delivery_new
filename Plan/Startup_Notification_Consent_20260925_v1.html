เมนูบัญชีลูกค้า/คนขับ/ร้าน มีสวิตช์เปิดปิด การปิดลบ token จากฐานข้อมูลและเครื่องก่อนแสดงสถานะปิด

จุดตรวจบนอุปกรณ์

  1. เปิดรุ่น 1.23.1+150 บน Xiaomi โดยออนไลน์และออฟไลน์ ตรวจว่าออกจากหน้าโลโก้
  2. เลือก “ยังไม่เปิด”: ไม่มีหน้าขอสิทธิ์ระบบและไม่มี token ใหม่
  3. เลือก “เปิด”: ขึ้นหน้าขอสิทธิ์ระบบหลังไดอาล็อกของแอป
  4. ปฏิเสธสิทธิ์ระบบ: หน้าตั้งค่าระบุว่ายังไม่พร้อม
  5. ปิดจากหน้า Settings: token DB/เครื่องถูกลบและไม่มี foreground notification
