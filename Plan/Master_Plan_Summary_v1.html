5) ลำดับการทำที่แนะนำ (รวมทุกแผนเป็น Batch)

Batch 0 — ปิดช่องโหว่ + ทำความสะอาดเงิน (เร็ว ทำก่อนเปิดโปรโมชั่น) เร่ง

  • W2: DROP policy เขียนตรงบน wallets/wallet_transactions + policy "Allow all" ของ bookings (security ค้างจากการสอบสวนวันแรก — ยังไม่ได้อยู่ในแผนไหน ผนวกเข้าตรงนี้)
  • W4: ย้อนเงินทดสอบ admin_adjustment +฿977,620 (จำเป็นก่อนตั้งถัง wallet)
  • W3: ซ่อม 3 กระเป๋า balance≠ledger · W5: E2E ถอน 1 รอบ

Batch 1 — เงินปลอดภัย (migration เดียวจบ 3 เรื่อง)

  • complete_booking: G2 GP server-side + ชดเชยคูปอง (แผนคูปอง A) + W1 เครดิตคนขับ wallet-order (job_payout)
  • cancel RPC: F2 status_origin + C2 คืนคูปอง
  • ทดสอบ E2E rollback ครบทุกสถานการณ์

Batch 2 — จอราคาตรงกัน (แอปเท่านั้น)

  • unified P1: unify การปัดทุกจอ (P1/P2) + แผนคูปอง D แก้ timezone คูปอง (C4)

Batch 3 — โปรโมชั่น Referral Wallet (v2 พร้อมเลย)

  • Phase 1 migration (ถัง 2 ใบ/ขั้นบันได/trigger จ่าย/withdraw hold) → Phase 2 แอป → Phase 3 admin-web

Batch 4 — ข้อมูลครบ ตรวจย้อนได้

  • unified P3: G1 snapshot GP rate ตอนสั่ง + audit + G4 เติมคอลัมน์สรุป + P3 coupon ใน webhook StoreOS

Batch 5 — นโยบาย/ขยาย (ทำเมื่อพร้อม)

  • unified P4 (F4 delivery log, F5 per-merchant, F8 shop status) · C5 UX ดัน wallet coupon · F3 รับออเดอร์ทาง POS (แผนแยก) · W6 กระเป๋าร้านค้า
