แผนแบ่งแท็บหน้า admin-web v1

2026-09-26 · ต่อจากหน้า Settings แบบแท็บ (admin-web 1.14.1) · ผู้ใช้เลือก "แบ่งแท็บหน้าที่ยาว" เรียงตามที่เสนอ

หลักการ

  • helper กลาง src/pages/pageTabs.js — ทุกหน้าใช้ตัวเดียวกัน (Settings ย้ายมาใช้ด้วย)
  • การ์ดชั้นบนติด data-tab="<id>" ในโค้ดหน้า (ชัดกว่าเดาจากหัวข้อ) · ไม่ติด = ตามการ์ดก่อนหน้า · data-tab="*" = แสดงทุกแท็บ
  • ซ่อนด้วย class hidden เท่านั้น — ฟอร์ม/ตาราง/ปุ่ม/ฟังก์ชันเดิมยังอยู่ใน DOM ทำงานเหมือนเดิม
  • แท็บแสดงจำนวน (badge) ได้ เช่น ออเดอร์รอคนขับ 3 · จำแท็บล่าสุดต่อหน้า (localStorage) · จอเล็กแถบแท็บปัดได้
  • หน้าที่เป็น "รายการ" ล้วน (เมนู, ออเดอร์, ผู้ใช้, รีวิว, ถอน/เติมเงิน) และหน้าที่มีชิปกรองอยู่แล้ว (ออเดอร์ฝากซื้อ) ไม่แบ่ง
