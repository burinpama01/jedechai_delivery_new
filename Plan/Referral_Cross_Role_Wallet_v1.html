ขอบเขต

เพิ่ม QR โค้ดแนะนำ และทำให้แอดมินกำหนดฐานรางวัลแต่ละคู่ได้ โดยใช้สถานะรางวัลและขั้นบันไดที่มีอยู่ ผู้ใช้กำหนดว่ารางวัลฝั่งลูกค้าเริ่มที่ 10 บาท

หน้าแอป

QR โค้ด + เงื่อนไขตามบทบาทและค่าที่แอดมินตั้งจริง

หน้า Admin

ช่องฐานรางวัลของแต่ละคู่ พร้อมตรวจค่าก่อนบันทึก

ฐานข้อมูล

จ่ายครั้งเดียวเมื่อเงื่อนไขสำเร็จ และไม่ให้ trigger เก่าจ่ายซ้ำ

ผู้ชวน → ผู้ถูกชวนเงื่อนไขฐานรางวัลผู้ชวน
ลูกค้า → ลูกค้าลูกค้าใหม่จบงานแรก10 บาท; ลูกค้าใหม่ไม่ได้รับ
คนขับ → ลูกค้าลูกค้าใหม่จบงานแรก20 บาท; ลูกค้าใหม่ไม่ได้รับ
ลูกค้า → คนขับคนขับใหม่จบงานแรก10 บาท; คนขับใหม่ไม่ได้รับ
ลูกค้า → ร้านร้านได้รับอนุมัติ10 บาทสำหรับค่าใหม่; ฐานข้อมูลเดิมคงค่าที่ตั้งไว้และต้องตรวจใน Admin
คนขับ → ร้านร้านได้รับอนุมัติใช้ค่าที่ตั้งอยู่แล้ว

ฐานรางวัลผู้ชวนคูณขั้นปัจจุบัน; ค่าเริ่มต้นแก้ได้ใน Admin

ลำดับทำงานและเกณฑ์ตรวจ

  1. เพิ่มช่องตั้งค่า Admin และ migration ที่แยกกติกาเก่าออกจากกติกาใหม่อย่างปลอดภัย
  2. ทำ QR ลิงก์ /invite?code= ให้เปิดหน้าสมัครในแอปพร้อมโค้ด; ผู้ยังไม่มีแอปเห็นโค้ดและลิงก์ติดตั้ง
  3. เพิ่มเงื่อนไขหน้าแอปจาก my_referral_summary และทดสอบ UI/SQL
  4. ทดสอบ migration บน staging, ทดสอบสมัครและจ่ายจริงก่อนเปิดใช้ production

ยังไม่อนุญาตให้รัน migration หรือเปลี่ยนรางวัล production จากแผนนี้
