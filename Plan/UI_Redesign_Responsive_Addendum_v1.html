ปัญหาที่ต้องแก้

artboard ทุกใบวาดบนกรอบ 390 × 844 ซึ่งเป็นมือถือขนาดกลาง ถ้าแปลงเป็นโค้ดแบบตรงตัวจะเจอ 3 อาการ

อาการเกิดเมื่อทางแก้ในโค้ด
เนื้อหาล้นจอ / RenderFlex overflowจอเตี้ยกว่า 844 (เช่น 360×640) หรือผู้ใช้ตั้งฟอนต์ใหญ่ห้ามใช้ Column ความสูงตายตัว ให้ห่อด้วย SingleChildScrollView / CustomScrollView
องค์ประกอบยืดจนน่าเกลียดแท็บเล็ต/จอพับ (≥600)ห่อด้วย JdcContentFrame จำกัดความกว้างและจัดกลาง
ปุ่มล่างถูกคีย์บอร์ดทับหน้าที่มีช่องกรอกresizeToAvoidBottomInset: true + วางปุ่มใน SafeArea ไม่ผูกกับ bottomNavigationBar
เครื่องมือพร้อมแล้วใน Wave 0 — lib/theme/jdc_layout.dart มี breakpoints, ระยะห่างมาตรฐาน, JdcContentFrame และตัวจำกัดการขยายตัวอักษร ติดตั้งใน MaterialApp.builder เรียบร้อย

ความกว้างเนื้อหาสูงสุดบนจอใหญ่: readableMaxWidth = 560 สำหรับรายการ/เนื้อหาทั่วไป และ formMaxWidth = 480 สำหรับฟอร์ม

สิ่งที่เอเจนต์ต้องทำทุกหน้า

  1. ใช้ final jdc = JdcColors.of(context); แล้วอ้าง token เท่านั้น
  2. ระยะห่างใช้ JdcSpacing · มุมใช้ JdcRadius · ความสูงปุ่ม/ช่องกรอกใช้ JdcTouch — ห้ามใส่ตัวเลขดิบซ้ำ
  3. เนื้อหาหลักห่อด้วย JdcContentFrame (จัดกลาง + จำกัดความกว้างบนจอใหญ่ + ใส่ระยะขอบตามขนาดจอให้เอง)
  4. ทุกหน้าที่เนื้อหายาวกว่าหนึ่งจอต้องเลื่อนได้จริง ทดสอบที่ความสูง 640
  5. ค่าที่ต่างกันตามขนาดจอให้ใช้ jdcByWidth(context, compact: …, medium: …) ห้ามเขียน if (width > 600) เอง
  6. รูปภาพใช้ AspectRatio หรือ FittedBox ไม่ใส่ width/height เป็นพิกเซลตายตัว
  7. ข้อความที่อาจยาวเกิน (ชื่อร้าน ที่อยู่) ต้องมี maxLines + overflow: TextOverflow.ellipsis
  8. ห้ามอ่าน MediaQuery.of(context).size ตรง ๆ ให้ใช้ context.windowClass / context.isCompact

โครงหน้าจอมาตรฐาน

@override
Widget build(BuildContext context) {
  final jdc = JdcColors.of(context);
  return Scaffold(
    backgroundColor: jdc.paper,
    resizeToAvoidBottomInset: true,
    body: SafeArea(
      child: JdcContentFrame(
        child: CustomScrollView(
          slivers: [
            // หัวเรื่อง / เนื้อหา
          ],
        ),
      ),
    ),
    bottomNavigationBar: const MerchantBottomNav(current: 0),
  );
}
ห้าม — SizedBox(width: 390), Container(height: 844), Positioned ด้วยพิกัดจาก artboard, MediaQuery.of(context).size.width * 0.37 และอื่น ๆ ที่ผูกกับขนาดจอเฉพาะรุ่น
