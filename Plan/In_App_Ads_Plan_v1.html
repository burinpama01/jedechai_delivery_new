1. เป้าหมาย

แอดมินอัปโหลดรูปโฆษณา/โปรโมท/ชวนเชิญ/โปรโมชั่น แยกตามฝั่ง ลูกค้า · คนขับ · ร้านค้า ได้จาก admin-web พร้อมเปิด/ปิด ตั้งวันเริ่ม-วันจบ และกำหนดว่ากดแล้วทำอะไร

2. ของเดิมที่มีอยู่

  • ตาราง banners (title, image_url, is_active, sort_order, page, coupon_code) — ใน production มี 1 แถว (ปิดอยู่)
  • admin-web Settings → "จัดการ Banner" (อัปโหลด/ซ่อน/ลบ) ผ่าน edge fn admin-actions
  • ลูกค้า: carousel หน้าแรก (page=home) และหน้าอาหาร (page=food) · กดแล้วโชว์โค้ดคูปอง
  • คนขับ/ร้านค้า: ยังไม่มี
ช่องโหว่ที่พบระหว่างสำรวจ (critical): policy "Service role full access" ของ banners ใช้กับ role public แบบ USING(true) WITH CHECK(true) + anon มี grant INSERT/UPDATE/DELETE → ใครก็ตามที่มี anon key (อยู่ในแอพ) เพิ่ม/แก้/ลบโฆษณาได้ เช่นเอารูปไม่เหมาะสมขึ้นหน้าแรก · แก้ใน migration ของงานนี้

3. การออกแบบ

3.1 ข้อมูล — ขยายตาราง banners เดิม (ไม่สร้างใหม่)

คอลัมน์ชนิดความหมาย
page (เดิม)textตำแหน่งแสดง (placement) — ดูตาราง 3.2

starts_at / ends_attimestamptz nullช่วงเวลาแสดง (null = ไม่จำกัด)
popup_frequencytext · CHECK once/daily/every_openความถี่ป๊อปอัป (default daily)

เหตุผลที่ใช้ page แบบมี prefix ต่อฝั่ง (เช่น driver_home) แทนการเพิ่มคอลัมน์ audience: แอพลูกค้าเวอร์ชันเก่าดึง page IS NULL OR page='home' → ค่าใหม่ทั้งหมดจะไม่หลุดไปโชว์ในแอพเก่า

3.3 กดแล้วทำอะไร

  • none — รูปอย่างเดียว
  • coupon — dialog โชว์โค้ด + ปุ่มคัดลอก (ของเดิม)
  • url — เปิดเบราว์เซอร์ภายนอก (url_launcher) รับเฉพาะ https://
  • screen — เปิดหน้าในแอพจากรายการที่กำหนด (allowlist): ลูกค้า: ชวนเพื่อน, คูปองของฉัน, กระเป๋าเงิน, สั่งอาหาร · คนขับ: ชวนเพื่อน (คนขับ), กระเป๋าเงิน, เติมเงิน, กะงาน, ผลงาน · ร้านค้า: แพ็กเกจ GP, คูปองร้าน, จัดการเมนู

3.4 ความปลอดภัย / RLS

  • ลบ policy Service role full access (service role bypass RLS อยู่แล้ว) และ policy อ่านซ้ำ Read active banners
  • policy อ่านสาธารณะใหม่: is_active AND (starts_at IS NULL OR starts_at<=now()) AND (ends_at IS NULL OR ends_at>now()) → ตัดเวลาที่ server ไม่พึ่ง client
  • REVOKE INSERT/UPDATE/DELETE/TRUNCATE จาก anon, authenticated (เขียนผ่าน admin-actions ด้วย service role เท่านั้น)
  • คง policy Admin full access ไว้ให้ admin-web อ่านแถวที่ปิด/หมดเวลาได้
  • edge fn: whitelist ฟิลด์ + validate page/action_type/URL/ช่วงวัน (ไม่ insert body ดิบแบบเดิม) · เพิ่ม action update_banner + สิทธิ์ใน _shared/admin-permissions.ts แล้ว sync ไป admin-web
